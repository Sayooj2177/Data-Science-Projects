# Airline Passenger Satisfaction Prediction using Machine Learning

## Project Overview

This project analyzes airline passenger satisfaction and builds machine learning models to predict whether a passenger is satisfied or dissatisfied.

## Dataset

The dataset contains passenger information, flight details, service ratings, and satisfaction status.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning

The project includes data preprocessing, exploratory data analysis, feature engineering, model training, and model evaluation.

## Models Used

- K-Nearest Neighbors (KNN)
- Other classification models
